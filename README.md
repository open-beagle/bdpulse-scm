# Bdpulse Scm

Bdpulse Scm 是 [BDPulse (原 Drone)](https://github.com/open-beagle) CI/CD 引擎的源码管理集成模块 (SCM)。

## 简介

封装了对各种外部源码托管平台（如 GitLab, GitHub, Gitea 等）的统一集成接口与 Webhook 处理逻辑。

